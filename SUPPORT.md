# Chat Export Studio Support

Thank you for using Chat Export Studio.

## Contact

- Email: marcel.missbach@me.com
- GitHub Issues: https://github.com/Marcello2020-dev/whatsapp-export-tools/issues

## What to include in a support request

- macOS version
- Chat Export Studio version
- Input type (ZIP, folder, Chat.txt/_chat.txt)
- Short description of the problem
- Relevant log excerpt (without sensitive personal data)

## Datenschutz / Privacy

The app processes chat exports locally on your Mac and does not upload chat content to external servers.
