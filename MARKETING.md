# Chat Export Studio

Chat Export Studio converts WhatsApp chat exports into clean, searchable, archive-ready outputs.

## Why Chat Export Studio

- Import as ZIP or extracted folder
- Export as Max HTML, Compact HTML, Sidecar HTML, Markdown, and EML
- Preserve original structure for traceable archiving
- Fast processing for large real-world chat histories
- Local-first: no cloud upload of chat content

## Use Cases

- Personal long-term archive
- Legal and compliance documentation
- Research and reporting workflows
- Migration from raw exports to readable formats

## Privacy

Chat data is processed locally on your Mac. No chat content is sent to external servers.

# Chat Export Studio (Deutsch)

Chat Export Studio wandelt WhatsApp-Chat-Exporte in saubere, durchsuchbare und archivierungsfähige Ausgaben um.

## Warum Chat Export Studio

- Import als ZIP oder entpackter Ordner
- Export als Max HTML, Compact HTML, Sidecar HTML, Markdown und EML
- Nachvollziehbare Ablage mit erhaltener Quellstruktur
- Schnelle Verarbeitung auch bei großen Chat-Verläufen

## Anwendungsfälle

- Persönliches Langzeit-Archiv
- Rechtssichere bzw. nachvollziehbare Dokumentation

## Datenschutz

Die Chat-Daten werden lokal auf deinem Mac verarbeitet. Es werden keine Chat-Inhalte an externe Server übertragen.
