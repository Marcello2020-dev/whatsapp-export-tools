# Chat Export Studio Privacy Choices

Last updated: May 8, 2026

This page explains privacy controls for Chat Export Studio.

## 1. File access control

The app can access only files and folders you explicitly select/authorize in the file picker.

## 2. Local-first usage

Core export processing runs locally on your Mac.

## 3. Online preview behavior

Some export variants include link preview enrichment.

If you prefer a stricter local-only path:

1. Select only the text-only HTML export variant.
2. Avoid preview-enabled variants for sensitive datasets.

## 4. Output retention

You choose the output location and can delete generated folders at any time.
