# Chat Export Studio Privacy Policy

Last updated: May 8, 2026

This Privacy Policy describes how Chat Export Studio handles information.

## 1. Controller

- Product: Chat Export Studio
- Publisher: Marcel Mißbach
- Contact: marcel.missbach@me.com

## 2. What the app does

Chat Export Studio is a local macOS app that converts user-selected WhatsApp export files into local HTML/Markdown outputs.

## 3. Data handled by the app

The app can process the following user-provided content:

- chat transcripts (for example `_chat.txt` or `Chat.txt`)
- local attachments in the selected export folder
- selected output folder paths

This processing is done on the user device.

## 4. Network access

The app may access the internet when generating link previews from URLs found in the selected chat content.

When this happens, third-party websites may receive technical request data (for example IP address, user-agent, and requested URL path) as part of normal web requests.

The app does not provide advertising SDKs and does not include third-party analytics SDKs in this repository.

## 5. Storage

- Export results are written to the user-selected output folder.
- App settings may be stored locally in the app sandbox.
- The app does not operate a dedicated backend service for storing user chat exports.

## 6. Tracking and advertising

- No in-app tracking across third-party apps or websites.
- No in-app behavioral advertising.

## 7. Data sharing

The app does not intentionally sell or broker personal data.

Data can be transmitted to third-party websites only when optional link preview retrieval is triggered by chat URLs.

## 8. Your choices

You control:

- which files/folders you grant to the app
- where outputs are written
- whether to use export variants that require online link previews

If you want fully local export behavior, use a text-only export variant.

## 9. Data deletion

The app stores outputs in locations chosen by the user. You can delete generated outputs and app sandbox data at any time.

## 10. Changes to this policy

This policy may be updated over time. The "Last updated" date above indicates the latest version.
